# SENTINEL-X
### Security Event Analysis & Threat Investigation

SENTINEL-X is a security analysis project focused on investigating simulated enterprise security events, identifying suspicious activity, mapping threats to MITRE ATT&CK techniques, and generating investigation reports with recommended response actions.

## Key Features

- Security event analysis
- Rule-based threat detection
- MITRE ATT&CK technique mapping
- Incident investigation
- Structured security reports
- Recommended response actions

## How It Works

1. Loads simulated security events.
2. Matches events against predefined detection rules.
3. Identifies suspicious activity based on rule matches.
4. Maps findings to relevant MITRE ATT&CK techniques.
5. Generates a structured investigation report.

## Project Files

- `mapper.py` - Main investigation engine
- `events.json` - Simulated enterprise security events
- `report.json` - Generated investigation report, if included

## Purpose

This project demonstrates foundational Blue Team skills in security event analysis, rule-based threat detection, incident investigation, and threat intelligence mapping.

## Disclaimer

For educational and defensive cybersecurity purposes. The project uses predefined detection instructions and simulated security data.
